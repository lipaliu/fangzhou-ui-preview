- M1 macOS Web：https://github.com/PuruVJ/macos-web （MIT）。借背景、内容窗、工具层之间的关系，应用于 03；不仿制系统桌面、系统菜单与假窗口控制。
- M2 Liquid Glass React：https://github.com/rdev/liquid-glass-react （MIT）。借通透胶囊、边缘亮线与成组操作，应用于 01 导航 / Dock 和共用浮层。成品使用 CSS backdrop-filter 近似，不声称已实现原项目的实时折射算法。
- M4 Dome Gallery / React Bits：https://github.com/DavidHDev/react-bits （MIT + Commons Clause）。借作品的空间排布与单张聚焦，应用于 02。此处是六张有限图集独立实现，不是原版无限球面拖拽器，未直接复制受限组件。
